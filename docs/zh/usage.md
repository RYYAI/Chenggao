# 使用

预览开在当前 Markdown 笔记右侧。笔记怎么写，预览就怎么排。不要在插件里再开一套编辑器。

英文版：[../usage.md](../usage.md)

## 打开预览

- 左侧功能区的叠页图标
- **⌘P** → `Chenggao: 打开排版预览`（英文界面为 `Open layout preview`）
- 笔记标题右键 → **用成稿预览打开**

## 图文卡片

顶栏切到 **图文卡片**。预览按 iPhone 备忘录截图分页，导出像素为 1206×2622。

- **导出图片**：写成 `图片/<笔记名>-01.png`
- **标题不落在页底**：默认开启

## 长文

顶栏切到 **长文**。

- **复制公众号格式**：粘贴到微信公众号编辑器
- **导出长图**：写成 `图片/<笔记名>-长文.png`
- 复制时也会保存 `<笔记名>.wechat.html`
