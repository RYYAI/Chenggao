# 使用

预览开在当前 Markdown 笔记右侧。笔记怎么写，预览就怎么排。不要在插件里再开一套编辑器。

英文版：[../usage.md](../usage.md)

## 打开预览

- 左侧功能区的叠页图标
- **⌘P** → `Chenggao: 打开排版预览`（英文界面为 `Open layout preview`）
- 笔记标题右键 → **用成稿预览打开**

## 图文卡片

顶栏切到 **图文卡片**。预览按推特信息流样式分页（头像、昵称、账号），导出像素为 1728×2304。

- 顶栏人物图标可改卡片上的**头像、名称、推特账号**（默认 `@username`），设置会保存在本机。

- **导出图片**：写成 `图片/<笔记名>-01.png`
- **标题不落在页底**：默认开启

## 长文

顶栏切到 **长文**。

- **复制公众号格式**：粘贴到微信公众号编辑器
- **导出长图**：写成 `图片/<笔记名>-长文.png`
- 复制时也会保存 `<笔记名>.wechat.html`

插件不需要账号，也不会访问远程服务器。复制走系统剪贴板，导出只写入当前库。
