# 使用

预览开在当前 Markdown 笔记右侧。笔记怎么写，预览就怎么排。不要在插件里再开一套编辑器。

## 打开预览

任选一种：

- 左侧功能区的叠页图标
- **⌘P** → `Chenggao: 打开排版预览`
- 笔记标题右键 → **用成稿预览打开**

换一篇笔记时，已打开的预览会跟着切到新笔记。

## 图文卡片

顶栏切到 **图文卡片**。预览按 iPhone 备忘录截图分页，导出像素为 1206×2622。

- **导出图片**：把每一页写成 `图片/<笔记名>-01.png`、`-02.png` …
- **图文排版 → 标题不落在页底**：默认开启。标题如果只能挤在一页最底下、正文全在下一页，会把标题和后面正文一起挪到下一页。

## 长文

顶栏切到 **长文**。右侧是公众号式预览。

- **主题 / 字体 / 字号 / 主题色**：在预览顶栏图标里改
- **复制公众号格式**：复制带样式的 HTML，粘贴到微信公众号编辑器
- **导出长图**：写成 `图片/<笔记名>-长文.png`
- 复制时也会在笔记旁边保存 `<笔记名>.wechat.html`

## 图片

笔记里的 `![[图片.png]]` 和标准 Markdown 图片都会解析。请保证图片在库里能被 Obsidian 找到。

## 命令

| 命令 | 作用 |
| --- | --- |
| Chenggao: 打开排版预览 | 打开或聚焦右侧预览 |
| Chenggao: 复制公众号格式 | 复制当前长文 |
| Chenggao: 导出图片到同级图片文件夹 | 按当前模式导出 PNG |
