# Contributing

This repository is the Chenggao Obsidian plugin.

```bash
npm install
npm test
npx eslint .
npm run build
```

`npm run build` writes `main.js` and `styles.css` at the repository root. Those two files belong in GitHub Releases, not in pull requests.

Open a Markdown note in a desktop vault, then run **Open layout preview** to check Cards, Article, export, and WeChat copy.
